## Todo List
할 일(Todo)을 간편하게 추가하고 관리할 수 있는 초간단 파이썬 스크립트입니다.
터미널에서 빠르고 가볍게 오늘 할 일을 정리할 수 있습니다.

## 기능
- 할 일 목록 조회
- 새로운 할 일 추가
- 완료된 항목 삭제
- JSON 파일을 통한 데이터 자동 저장

## 설치 및 실행 방법
1. 레포지토리 클론 git clone https://github.com/username/TodoList.git cd TodoList
2. 스크립트 실행 Bash셸 -> python todo.py
3. 입력값
- 메뉴 선택 (1: 목록, 2: 추가, 3: 완료/삭제, 4: 종료)
- 할 일 내용 또는 번호 입력

## 사용예시:
- --- [1] 목록 [2] 추가 [3] 완료/삭제 [4] 종료 ---
- 선택: 2
- 추가할 할 일: 파이썬 공부하기

## 결과:
- --- [1] 목록 [2] 추가 [3] 완료/삭제 [4] 종료 ---
- 선택: 1
- 1. 파이썬 공부하기

## 요구사항
- Python 3.x
- 추가 라이브러리 없음 (표준 라이브러리 `json`, `os`만 사용)
